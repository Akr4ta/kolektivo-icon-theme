# Credits
This icon theme combines MoreWaita with the Sweet cursor theme and a modified version of the Amy-Plasma-Themes folder theme.

My work consisted of modifying the Amy-Plasma-Themes theme to align it with Adwaita guidelines and combining all these themes into one.

# Install
Download the .zip file.

Extract the archive and move either the kolektivo-nokto or kolektivo-blue folder to icons directory ~/.local/share/icons/ (Create this directory if it doesn't exist).

Note: Ensure that you have the Adwaita icon theme installed.
